# doc-translator

Rewrites an existing document (Obsidian note or file) for a different target audience, preserving meaning while adapting language, depth, and framing.

## Audiences

| Код | Аудитория | Стиль |
|---|---|---|
| `dev` | Разработчики | Техническая точность, код, алгоритмы, edge cases |
| `legal` | Юристы | Формальный язык, акцент на обязательствах, правах, рисках |
| `biz` | Бизнес / менеджмент | Ценность, метрики, сроки, ROI, без технических деталей |
| `investor` | Инвесторы | Рынок, конкуренты, потенциал, риски, цифры |
| `simple` | Упрощённая / нетехническая | Аналогии, простые слова, минимум терминов |

## Workflow

1. Определи источник: путь к файлу в Obsidian (`notes-vault/...`) или текст прямо в чате.
2. Определи целевую аудиторию (из таблицы выше).
3. Прочитай исходный документ (`read`).
4. Перепиши с учётом аудитории:
   - Сохраняй структуру (заголовки, разделы).
   - Адаптируй язык, детализацию и примеры.
   - Не добавляй информацию, которой нет в оригинале.
5. Сохрани результат рядом с оригиналом, добавив суффикс: `(для разработчиков)`, `(для юристов)` и т.д.
6. Предложи также запушить в GitHub.

## Примеры запросов

- «Сделай версию заметки про Network Swap для разработчиков»
- «Перепиши документ для ВЭД для юристов»
- «Сделай упрощённую версию смарт-контракта для бизнеса»
