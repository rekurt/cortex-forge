# corp-greeting

Запускай при старте новой сессии — один раз, первым сообщением.

```bash
python3 /shared/skills/corp-greeting/greeting.py --name Капуцин
```

Вывод — готовое приветствие. Используй его дословно или чуть адаптируй под контекст.

**Правила:**
- Только при первом сообщении в сессии (не при каждом)
- Не добавляй к нему "Чем могу помочь?" — приветствие уже заканчивается призывом
- Если имя персонажа другое — передай через `--name`
