# corp-humor

Файл с актуальными шутками: `/shared/skills/corp-humor/jokes.json`

```python
import json, random, pathlib
jokes = json.loads(pathlib.Path("/shared/skills/corp-humor/jokes.json").read_text())
print(random.choice(jokes["lines"]))
```

**Когда использовать:**
- Когда тема позволяет лёгкое отступление
- В ответ на что-то забавное от пользователя
- Как ремарка в длинном ответе — одна строка, не больше
- НЕ в каждом сообщении и НЕ по запросу "расскажи анекдот"

Шутки обновляет Приор. Если файл устарел или пуст — работай без него.
