# Корпоративная база знаний CortexForge

Общая папка для всех инстансов. Храните здесь документы, заметки, протоколы встреч, инструкции.

## Структура

```
shared/docs/
  README.md           ← этот файл
  <name>/             ← личная папка каждого инстанса
    *.md              ← документы
  common/             ← общие документы для всех
    *.md
```

## Как добавить документ

Сохрани `.md` файл в `/shared/docs/<твоё-имя>/` или `/shared/docs/common/`.
Поиск по всем документам доступен через скилл `corp-docs`.
