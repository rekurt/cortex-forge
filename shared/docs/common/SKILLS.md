# 🧩 Скиллы — что умеет твоя обезьянка

Скилл — это специализированная инструкция, которая превращает ассистента из «умного чат-бота» в инструмент под конкретную задачу. Подключается автоматически — тебе не надо ничего активировать.

---

## 🔍 Compliance — проверка контрагентов

**Как попросить:**
- «Проверь контрагента ИНН 7701234567»
- «Пробей ООО Ромашка»
- «KYC перед подписанием договора»

**Что проверяет:**
- ФНС: директор, учредители, адрес, статус юрлица
- Санкционные списки: OFAC, ЕС, ООН, Великобритания
- ФССП: долги и исполнительные производства
- Банкротство (Федресурс)
- Лицензии ЦБ РФ, массовый адрес, номинальный директор
- Негативные упоминания в СМИ

**Юрисдикции:** Россия (ИНН/ОГРН), Беларусь (УНП), Казахстан (БИН), Великобритания, Германия, Кипр, Швейцария, 130+ стран.

**Результат:** 🟢 низкий риск / 🟡 средний / 🔴 высокий / ⛔ отказ

> ⚠️ Украина — автоматический отказ. Встроено в методологию.

---

## 📁 Корпоративная база знаний (corp-docs)

Общее хранилище документов для всей команды RubX.

**Как попросить:**
- «Сохрани это в базу знаний» — ассистент сохранит заметку, файл или фрагмент
- «Найди в базе знаний инструкцию по договорам»
- «Что есть в базе по онбордингу?»

Документы доступны всем ассистентам в команде. Пишешь ты — найдёт коллега.

---

## 📅 Яндекс (Трекер, Календарь, Телемост, Почта)

Единая точка входа в Яндекс-инфраструктуру через OAuth.

**Трекер:**
- «Покажи мои задачи»
- «Создай задачу: ...»
- «Переведи задачу в статус В работе»

**Календарь:**
- «Покажи мои встречи на сегодня»
- «Создай событие завтра в 14:00 — созвон с командой»

**Телемост:**
- «Создай конференцию на пятницу в 11:00»

**Почта:**
- «Отправь письмо Ивановой: ...»

---

## 💬 Мессенджер между ботами (corp-messenger)

Ассистенты в команде могут передавать сообщения друг другу.

**Как попросить:**
- «Передай Дмитрию: завтра встреча в 10:00»
- «Есть ли у меня сообщения от других ботов?»

Изоляция полная — прочитать чужие сообщения нельзя.

---

## 😄 Корпоративный юмор (corp-humor)

Пул приматных острот — обновляется раз в неделю администратором системы.
Ассистент использует органично, между делом. Не каждое сообщение — обещаем.

---

## 🛠️ Как создать свой скилл

Скилл — это набор инструкций под твою задачу. Бухгалтер, юрист, техподдержка — у каждого может быть своё.

**Три шага:**
1. Опиши задачу: «Хочу чтобы ты всегда знал наш шаблон договора»
2. Дай материал: прикрепи файл или опиши структуру
3. Готово — ассистент сохранит скилл и будет использовать его автоматически

**Примеры скиллов которые можно создать:**
- 📄 Шаблоны документов (договор, акт, счёт)
- 📊 Формат отчётов (откуда брать, как форматировать)
- 👤 Контакты команды и зоны ответственности
- 🔁 Повторяющиеся сценарии («при вопросе про X — сначала уточни Y»)
