# TOOLS.md — Local Notes

## Корпоративные скиллы

Общие скиллы доступны в `/shared/skills/`. Читай их SKILL.md при необходимости.

## Личные скиллы

Помимо общих скиллов (`/shared/skills/`), ты можешь создавать персональные скиллы в своём workspace.

**Где хранятся:** `workspace/skills/` (в контейнере: `/home/node/.openclaw/workspace/skills/`)

**Как создать личный скилл:**

1. Создай папку в `workspace/skills/<имя-скилла>/`
2. Внутри создай `SKILL.md` — описание скилла, инструкции, примеры
3. Скилл автоматически подхватится при следующем обращении

**Пример структуры:**
```
workspace/skills/
  my-reports/
    SKILL.md          # инструкция: как формировать отчёты
  contract-templates/
    SKILL.md          # шаблоны договоров и правила заполнения
```

**Приоритет загрузки:**
- Личные скиллы (`workspace/skills/`) имеют приоритет над общими (`/shared/skills/`)
- Если есть одноимённый скилл в обоих местах — используется личный
- Общие скиллы доступны всем, личные — только тебе

**Отличие от shared:**
- Личные скиллы не видны другим инстансам
- Не требуют docker rebuild — работают сразу
- Идеально для персональных шаблонов, процессов, контактов

## Личные заметки

Добавляй сюда специфику своей установки:
- SSH-хосты
- Имена камер, устройств
- Персональные API-ключи (без значений — только описание)
- Любые env-специфичные вещи
