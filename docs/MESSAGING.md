# MESSAGING.md — Межинстансный мессенджер

## Принцип работы

```
nikita-бот                 message-broker              alexey-бот
    │                           │                           │
    │  POST /send               │                           │
    │  {to:"alexey",            │                           │
    │   message:"привет"}       │                           │
    ├──────────────────────────►│                           │
    │                           │  кладёт в inbox[alexey]   │
    │  200 OK                   │                           │
    │◄──────────────────────────┤                           │
    │                           │                           │
    │                           │   GET /inbox              │
    │                           │◄──────────────────────────┤
    │                           │                           │
    │                           │  [{from:"nikita",...}]    │
    │                           ├──────────────────────────►│
```

## Безопасность

| Угроза | Защита |
|---|---|
| Инстанс A читает inbox B | Нельзя — брокер проверяет ключ, отдаёт только свой inbox |
| Инстанс A отправляет от имени B | Нельзя — sender определяется по API-ключу, не по body |
| Внешний запрос к брокеру | Нельзя — порт не проброшен наружу, только Docker-сеть |
| Перехват сообщений | Docker-сеть изолирована; при необходимости добавить TLS |

## Настройка нового инстанса

1. `make add-user` автоматически генерирует `BROKER_KEY` и добавляет в `.env`
2. Глобальный `.env` получает `BROKER_KEY_<NAME_UPPER>=<key>`
3. Брокер перезапускается и видит новый ключ

## Примеры использования для ассистентов

**Никита просит своего ассистента передать задачу Алексею:**
```
Скажи ассистенту Алексея, что нужно подготовить отчёт по спринту к пятнице
```

Ассистент Никиты делает:
```bash
curl -X POST http://message-broker:8080/send \
  -H "Authorization: Bearer $BROKER_KEY" \
  -d '{"to":"alexey","message":"Привет от Никиты: нужен отчёт по спринту к пятнице"}'
```

**Ассистент Алексея проверяет входящие:**
```bash
curl http://message-broker:8080/inbox \
  -H "Authorization: Bearer $BROKER_KEY"
# → [{"from":"nikita","message":"Привет от Никиты: ...","ts":1234567890}]
```

## Ограничения текущей версии

- Сообщения в памяти (не persistent) — перезапуск брокера очищает очередь
- Нет push-уведомлений — инстанс сам polling-ит inbox (или по запросу пользователя)
- Нет истории — только текущие непрочитанные

**При необходимости persistence:** заменить `deque` в broker.py на SQLite.
